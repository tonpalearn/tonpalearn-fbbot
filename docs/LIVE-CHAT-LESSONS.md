# บทเรียนจากแชทสดของต้น → กติกาบอต (18 พ.ย. 69)

ที่มา: แชทจริงจาก Messenger export 61 ห้อง / 473 ข้อความ (ข้อมูลดิบอยู่ในเครื่องเท่านั้น ไม่ระบุชื่อลูกค้า)

| # | ที่เจอในแชทสด | กติกาบอต (บังคับด้วยโค้ด) |
|---|---|---|
| 1 | ลูกค้าพิมพ์เองตั้งแต่ข้อความแรก (ไม่กดปุ่มแอด) → บอตเดิมโยนหาคนทุกห้อง แล้วเงียบ | คนใหม่ทักเอง → เข้าโฟลว์คัดลูกค้า (`startOpenQualifier`) · กติกาคำสำคัญของต้นยังมาก่อน · มาก่อน FAQ |
| 2 | ข้อความซ้อน 3–4 อันก่อนคนพูด · ทักทายซ้ำ | ทักทายเฉย ๆ → **ข้อความเดียว** ถามยอดขาย + 4 ปุ่ม (`VOICE.openHello`) |
| 3 | ลูกค้าบอกเรื่องเฉพาะ แต่ได้เมนูบริการกลับ | สะท้อนคำลูกค้าก่อนถาม: `ได้ครับ เรื่อง "…"` + คำถามข้อเดียว (`reflectTask`) |
